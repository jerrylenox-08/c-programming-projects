# C Programming Portfolio

A collection of foundational C programming projects showcasing control structures, data validation, logical operators, and modular function design.

## Projects

### 1. [Bank Account Qualification System](./bank-qualification-system)
- **Language**: C (C99)
- **Key Concepts**: `unsigned char`, `double`, `bool`, logical OR (`||`), input validation (`scanf`), batch `for` loop processing.
- **Description**: Evaluates customer eligibility based on age and monthly income thresholds.

### 2. [Simple Calculator](./simple-calculator)
- **Language**: C
- **Key Concepts**: Basic I/O, conditional logic (`if/else`), floating-point operations.
- **Description**: A CLI calculator performing basic mathematical operations.
